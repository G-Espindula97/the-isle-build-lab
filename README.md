# 🦖 The Isle Evrima — Build Lab

Planejador de builds de mutações para **The Isle: Evrima**.  
Gratuito, sem cadastro, funciona direto no navegador.

🔗 **[Acessar o Build Lab](https://the-isle-build-lab.netlify.app)**

---

## ✨ Funcionalidades

- **Escolha seu dinossauro** — todos os dinos do Evrima disponíveis
- **Planejador de mutações** — selecione até 16 slots com recomendações inteligentes
- **Porcentagens reais** — efeitos confirmados por estágio (Juvenil → Sub-adulto → Adulto → Prime)
- **Comparação de builds** — compare duas builds lado a lado com efeitos detalhados
- **Compartilhar builds** — gere um código e compartilhe com amigos
- **Importar builds** — cole o código de uma build para carregá-la
- **Dossier de campo** — veja as stats do dino no estágio Prime
- **Sons de clique** — feedback sonoro suave
- **100% offline** — um único arquivo HTML, sem servidor, sem login

---

## 🚀 Como usar localmente

Baixe o arquivo `index.html` e abra no navegador. Não precisa de nada mais.

---

## 📦 Como publicar no GitHub Pages

1. Faça fork deste repositório (ou crie um novo)
2. Faça upload do `index.html`
3. Vá em **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Salve — em alguns minutos o site estará no ar
